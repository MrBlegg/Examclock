Exam timing

Exam length

Enter the exam length to show the total exam time.

Enter a 24-hour time, such as 09:00.

Enter a start time and the finish time will be calculated automatically from the exam length. Alternatively, press Start exam now, which rounds up to the next whole minute. Leave the start time blank to enter the finish time manually below.

Extra finish times

Rest breaks
Use Add custom finish time and type in the candidate's finish time.
Disruption
Choose Clear start time and type in the new finish time. Extra time finishes update automatically, but the start time no longer shows on screen.
Several exams in one room
Use Add custom finish time for each exam, with the subject as its heading. You can show up to four finish times.

Extra time is rounded up to the next whole minute.
